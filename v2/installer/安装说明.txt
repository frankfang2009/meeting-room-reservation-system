会议室预约系统 V2.5.1 全新安装说明
====================================

1. 本安装包只支持 64 位 Windows 10/11。
2. 先完整解压 ZIP，不要直接在压缩包预览窗口内运行，也不要单独复制 BAT。
3. V2 不读取、不迁移也不删除任何 V1 文件夹、账号、笔录室或预约数据。
4. 如确定舍弃 V1，请先在旧系统中取消开机启动、停止服务，再由您自行删除旧目录。
5. 双击“安装V2.5.1.bat”。正式安装目录固定为“%ProgramFiles%\会议室预约系统V2”，
   该目录必须不存在或完全为空；安装程序不接受自选目录。
6. 共享盘、U盘、移动盘和网盘同步目录不受支持。安装器使用 Windows Known Folder
   API 解析 Program Files，不信任可被继承或修改的环境变量路径。
7. Windows 请求管理员授权时选择“是”。取消授权不会安装 V2。
8. 安装完成后在本机完成首次设置；完成前服务只监听 127.0.0.1:8080。
9. 首次设置完成后才开放同一局域网访问，固定使用 TCP 8080。
10. 如 TCP 8080 已被其他程序占用，安装会明确停止；安装器不会结束未知进程，
    也不会自动改用随机端口。
11. 安装后的程序文件允许普通用户读取和执行；data、backups、logs 以及身份密钥
    只允许 SYSTEM 和 Administrators 访问。①–⑥维护工具均会请求 UAC。
12. 系统每天本地时间 02:00 自动备份；错过触发时由同一计划任务补跑且禁止并发。
    “⑥ 从备份恢复”只接受当前 V2 安装受保护备份目录中、身份和哈希均通过的备份。

本包在普通用户 Windows 10/11 的 UAC、SmartScreen/EDR、计划任务、重启和
第二台局域网电脑验收全部通过前只能作为候选版，不得作为正式外发版本。
