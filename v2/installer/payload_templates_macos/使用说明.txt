会议室预约系统 V2 · macOS 自托管版 使用说明
=============================================

一、首次运行（只需要做一次）
------------------------------
1. 双击下载到的 DMG 文件，会挂载出一个磁盘图标。
2. 把里面的「会议室预约系统V2-macOS」文件夹拖到「应用程序」或任意可写位置。
   注意：不要直接在 DMG 里双击启动；拖出来之后再推出 DMG。
3. 首次双击「启动.command」时，macOS 会提示“无法验证开发者”。
   请在文件夹中右键点「启动.command」，选“打开”，再点一次“打开”即可放行；
   之后双击启动不再提示。也可以改用终端命令：
     xattr -dr com.apple.quarantine 应用文件夹路径
   请不要为此关闭系统安全设置。
4. 启动后会自动打开浏览器访问 http://127.0.0.1:8080 ，按向导完成首次设置：
   创建首名管理员账号（没有默认账号或默认密码）、添加笔录室、设定工作时间。

二、日常使用
-------------
- 双击「启动.command」启动服务；保持该终端窗口开启即服务在线。
- 关闭终端窗口或双击「停止.command」即可停止服务；再次使用重复启动即可。
- 首次设置完成后，同一可信局域网内的其他设备可访问
  http://<本机局域网IP>:8080 登录使用；公开大屏地址无需登录。
- 注意：本系统使用 HTTP 明文传输，请仅在本机或可信局域网内使用，
  不要映射到公网。

三、数据、备份与卸载
---------------------
- 全部业务数据保存在应用文件夹内的 data、backups、logs 三个目录中；
  备份整个文件夹即备份全部数据。
- 服务每天 02:00 自动备份数据库（错过会在下次启动后补做），保留最近 30 份。
- 删除整个应用文件夹即彻底卸载，系统无残留。

四、升级到新版本
-----------------
由维护人员在原 Mac 上操作。旧版和新版各用一个文件夹，核对完成前请同事暂停使用。

1. 在「系统状态」打开发布页，下载新版 DMG，按发布说明核对 SHA-256。在可写位置新建
   一个以新版版本号命名的文件夹，把 DMG 里的整个应用文件夹拖进去，推出 DMG。先不要启动新版。
2. 请管理员记下现有笔录室、工作时间和一条便于核对的预约。等所有人停止修改后，在旧版
   「系统状态 → 最近备份」点「立即备份」，确认已追平。在旧应用文件夹双击「停止.command」，
   等待显示“V2 服务已停止”。停止或备份失败，先处理提示，再继续复制。
3. 保留完整旧文件夹。在访达中选中旧目录下的 data、backups、logs，按 ⌘C，到新应用文件夹
   （与「启动.command」同级）按 ⌘V。复制整个目录会带上隐藏的密钥与安装身份。
   如果目标已有这三个目录中的任何一个，或提示“替换 / 合并”，请取消。另建空目录，
   从 DMG 重新拖出一份未启动的新程序，再复制。等三个目录全部复制完成。
4. 从新目录双击「启动.command」。用原账号登录，核对「系统状态」的程序版本、工作时间、
   最近备份，以及原笔录室和预约。若出现首次设置向导，停在该页，检查所复制的数据。
   全部核对后再通知同事恢复使用，以后从新目录启停。

需要退回时：
- 新版尚未接收预约或其他业务变更：确认新版服务已停止后，从保留的旧目录启动，
  用原账号核对预约。若旧版恢复使用，以后重试升级须重新备份并从停止后的旧目录复制。
- 新版已有预约、取消、账号或设置变更，或不能确定是否有变更：暂停使用并妥善保留两份目录，
  交维护人员从含最新数据的新版目录恢复。直接启用旧目录会漏掉升级后的变更。

五、遇到问题
-------------
- 启动失败：确认 8080 端口没有被其他程序占用，再重新启动。
- 详细原因记录在应用文件夹 logs/service.log 中。
