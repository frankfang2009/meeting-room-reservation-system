会议室预约系统 V2 · macOS 自托管版 使用说明
=============================================

一、首次运行（只需要做一次）
------------------------------
1. 双击下载到的 DMG 文件，会挂载出一个磁盘图标。
2. 把里面的「会议室预约系统V2-macOS」文件夹拖到「应用程序」或任意可写位置。
   注意：不要直接在 DMG 里双击启动；拖出来之后再推出 DMG。
3. 首次双击「启动.command」时，macOS 会提示“无法验证开发者”。
   请在文件夹中右键点「启动.command」，选“打开”，再点一次“打开”即可放行；
   之后双击启动不再提示。也可以改用终端命令：
     xattr -dr com.apple.quarantine 应用文件夹路径
   请不要为此关闭系统安全设置。
4. 启动后会自动打开浏览器访问 http://127.0.0.1:8080 ，按向导完成首次设置：
   创建首名管理员账号（没有默认账号或默认密码）、添加笔录室、设定工作时间。

二、日常使用
-------------
- 双击「启动.command」启动服务；保持该终端窗口开启即服务在线。
- 关闭终端窗口或双击「停止.command」即可停止服务；再次使用重复启动即可。
- 首次设置完成后，同一可信局域网内的其他设备可访问
  http://<本机局域网IP>:8080 登录使用；公开大屏地址无需登录。
- 注意：本系统使用 HTTP 明文传输，请仅在本机或可信局域网内使用，
  不要映射到公网。

三、数据、备份与卸载
---------------------
- 全部业务数据保存在应用文件夹内的 data、backups、logs 三个目录中；
  备份整个文件夹即备份全部数据。
- 服务每天 02:00 自动备份数据库（错过会在下次启动后补做），保留最近 30 份。
- 删除整个应用文件夹即彻底卸载，系统无残留。

四、升级到新版本
-----------------
1. 管理员在网页「系统状态」页会看到“有新版本”提示，点击链接打开发布页。
2. 下载新版本 DMG 并拖出新文件夹。
3. 停止旧版本服务（「停止.command」）。
4. 把旧文件夹中的 data、backups、logs 三个目录完整拷贝到新文件夹（合并）。
5. 双击新文件夹的「启动.command」，账号、预约和设置全部保留。
   系统只提示新版本，不会自动下载或自动安装任何更新。

五、遇到问题
-------------
- 启动失败：确认 8080 端口没有被其他程序占用，再重新启动。
- 详细原因记录在应用文件夹 logs/service.log 中。
