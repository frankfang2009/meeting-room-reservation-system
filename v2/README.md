# 会议室预约系统 V2.0.0

V2 是一个全新安装基准，不读取或迁移 V1 数据库。它由同源部署的 React 前端、
Flask JSON API 和 SQLite 数据库组成，面向单位 Windows 主机及局域网桌面浏览器。

## 目录

- `frontend/`：从已冻结视觉原型导入的 React/Vite 源码。生产构建不得使用合成数据。
- `backend/`：Flask 应用、V2 数据库、API、首次设置和运行服务。
- `installer/`：V2 全新安装、候选包制作和未来 V2 累计更新基线。
- `tests/`：跨前后端契约、打包与端到端验收辅助。

## 不变量

- V2 数据库必须包含 `product_generation=2`；发现 V1 数据库时拒绝启动。
- 预约、占用时段和预约事件必须在同一事务中提交。
- 员工可以查看单位共享日历详情，但只能修改或取消自己的预约；管理员可管理全单位预约。
- 员工历史仅限本人；管理员历史可查看全单位并按用户筛选。
- 公开大屏只使用服务端白名单投影，绝不返回案号、备注、标签、部门或工作人员身份。
- 首次设置完成前只允许回环地址访问，完成后才可开放局域网服务。
- V2 客户端不需要 Node.js；发布包只包含预构建静态资源和冻结 Python 运行时。

## 发布边界

自动化测试不能替代普通用户 Windows 10/11 的 UAC、SmartScreen/EDR、计划任务、
重启和第二台局域网电脑验收。正式验收完成前，任何产物都只能标记为候选版。
