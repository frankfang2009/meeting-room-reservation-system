# 更新记录

## V2.2.1（macOS 自托管版）

- 版本定位：V2.2.0 的 macOS 平台交付，业务功能与 V2.2.0 完全一致；数据库 schema 保持 v2，不新增业务表和字段。
- 新增 macOS arm64（Apple Silicon）自托管便携包：同一份 `v2app`/`service.py` 打包 python-build-standalone 冻结运行时（SHA-256 锁定）与哈希 wheelhouse；便携目录 `app/ + runtime/ + data|backups|logs`，删除文件夹即彻底卸载。
- 新增 DMG 分发形态：便携包 zip 是可复现事实源（两次独立构建字节一致，进入 CI 门禁）；DMG 由校验过的 zip 内容生成并反向核对关键文件哈希，不承诺 DMG 字节级可复现。
- 新增 `启动.command`/`停止.command`：双击启动自动开浏览器、从 DMG 挂载卷启动被明确拒绝并提示拖出；停止沿用 `--stop` 的 pid + 回环控制语义。
- 新增仅 macOS 版启用的受控版本检查：至多每 24 小时读取一次 GitHub Release 固定清单（HTTPS、10 秒超时、64 KiB 上限、严格 schema），只在管理员系统状态页显示"有新版本"与服务端构造的发布页链接；不自动下载、不自动安装、不发送任何本机数据；Windows 版与开发态保持关闭，继续维持"在线/自动升级"排除。
- macOS 版首次启动自动生成安装身份（`install.json`/`install_id`，`EDITION` 标记区分版本形态）；`service.py` 运行时白名单与失败提示按平台分支。
- 新增 macOS CI 验收车道：PR/main 在真实 macOS runner 上跑全量测试；版本标签触发候选构建——双构建字节一致 → DMG 生成与内容校验 → 从 DMG 出发的 8 步真实验收（卷守卫、拖出、启动、首次设置、LAN 切换、登录、自动备份落盘、干净停止）。
- Windows 交付链不变：新装包与 V2.1.0→当前版本累计升级包照常构建，升级验收腿的产物名改为跟随 `v2/VERSION`；来源矩阵仍仅含冻结 V2.1.0。
- 外发规则按交付物分类：macOS 自托管版以 GitHub Release 为正式分发渠道（发布说明附 SHA-256，未签名首启需右键打开）；Windows 安装包/升级包在真实 Windows 实机验收与 Authenticode 签名完成前继续禁止正式外发。
- 首版明确不做：launchd 开机自启、Developer ID 签名与公证、一键自动更新、x86_64/universal2、`.app` 原生壳、Windows↔macOS 数据迁移承诺。

## V2.2.0（候选版）

- 新增员工与管理员共享的数据中心：员工仅能查看本人，管理员可查看全单位、本人或指定人员；权限由服务端强制执行。
- 新增有效预约、已结束预约、有效预约时长与取消率四项指标，以及按周、人员/个人标签、笔录室、星期×时段分布。
- 个人中心简化为纯偏好设置页，移除“我的活动”统计页；个人统计的唯一入口是数据中心本人视角，全应用只有一套统计口径。
- 新增按当前范围导出 CSV 办件明细，固定 15 个字段、UTF-8 BOM、CRLF、20,000 行上限、公式注入防护与安全审计。
- 新增仅支持冻结 V2.1.0 来源的离线累计升级包：先备份和校验数据，再事务替换程序，健康检查失败时回滚；不扫描或接触 V1。
- 评审修复：升级替换 `app`/`runtime` 后重新固化受保护 DACL（回滚与恢复路径同样固化），双击升级在 UAC 前只读公开版本文件、不再触碰仅管理员可见的安装身份；升级 BAT 补齐 UTF-8 输出环境与免暂停钩子；断电遗留的旧程序临时目录在回滚/恢复时自动清理，再次双击同一升级包即可完成升级。
- 评审修复：报告结束日期上界与预约历史一致（9999-11-30），极端日期返回 422 而非 500；CSV 导出改为数据库侧 LIMIT 封顶后再判定超限；数据中心标签四槽位颜色与全应用 `TAG_COLORS` 调色板完全同值。
- 新增 T1 层 Windows 真实升级验收：CI 在 Windows runner 上先安装冻结 V2.1.0，再用 V2.2.0 累计升级包执行真实升级，校验版本、install_id、业务数据保留与 DACL 边界。
- 数据库 schema 继续保持 v2；真实 Windows 升级、普通用户、签名和受控分发门禁未完成前，安装包与升级包都只能标记为候选版。

## V2.1.0（候选版）

- 准备以 Apache-2.0 公开源代码，补齐社区、安全和双语入口文档；源码公开不等于正式发布未签名安装包。
- 登录页换为项目自有的中性日程入口 SVG，并清理当前树中的私有设计路径与第三方品牌模仿引用。
- 普通 CI 与候选构建拆分：PR/main 不上传安装包，候选只从 main 手动或匹配版本标签运行；V1 Windows 工作流改为路径触发。
- 修复预约表单中较长的自定义标签名称溢出按钮边界的问题，单行四标签布局保持不变。
- 收紧个人中心页头与活动数据通栏布局，工作时间改为整行可点击入口，同时拉开侧栏输入与保存操作间距。
- 增加 schema v1→v2 原子、幂等迁移框架，新鲜安装直接使用 schema v2；受验证的
  schema v1 备份可在恢复事务中迁移，失败时保持 fail-closed 并回滚现场。
- 管理员可在系统状态页修改工作时间，既有预约时间保持不变。
- 用户可设置默认预约标签和 15/30/60 分钟提醒提前量；提醒仍仅在页面打开时工作。
- 管理员可按笔录室隐藏公开大屏投影，不影响共享预约日历与只读集成接口。
- 未开始预约支持手动复制对外提醒信息，并提供按账号隔离的个人模板；变量固定为
  当事人姓名、日期、开始时间、结束时间和笔录室，不接入任何自动发送通道。
- 对外提醒的系统默认文案仍是实施占位示例，等待用户另行定稿。
- 新增 T1 Windows 真实安装验收自动化：PR/main 在免费 Windows CI 上完成
  真实 BAT 安装、首次设置与 LAN 重启、预约/大屏/备份冒烟、启停身份校验链、
  端口冲突拒绝、数据库损坏 fail-closed 与 DACL 边界（E43、E44）。
- 修复真实 Windows 上备份必然失败的两个缺陷：备份管道对只读句柄执行
  fsync 抛 Errno 9；cp1252 控制台/pythonw 无控制台下中文报告把已成功的
  备份标记为失败。修复前 POSIX 自动化从未暴露（E43、E44）。
- 版本号、安装启动器、候选包名称、SBOM 元数据和契约统一提升至 V2.1.0。

## V2.0.0（候选版）

- 建立与 V1 完全隔离的 fresh-install 产品代际。
- 使用 React 冻结视觉稿、Flask JSON API、SQLite 与同源桌面局域网部署。
- 提供全单位共享预约日历、本人/管理员分级管理、修改与取消、revision 并发保护和追加式预约事件。
- 提供预约记录、网页提醒、全局/个人标签、用户偏好、笔录室与用户管理。
- 提供独立的临近预约与他人变更通知，确认回执按类型和 revision 隔离。
- 提供服务端白名单和姓名脱敏的公开局域网大屏。
- 提供首次本机配置、系统状态、诊断、备份和只读集成令牌。
- 提供带安装身份的安全启停、Windows 只读 PID 探测、RFC1918 局域网地址与轮转运行日志。
- 新建 V2 全新安装事务与后续 V2-only 累计升级的非生产安全基线，不迁移或删除
  V1 数据；V2.0.0 不宣称支持在线升级。
- 第三方独立复核后加固正式安装基线：固定 Program Files、显式 Windows DACL、
  SYSTEM 运行时模块白名单和受保护的 secret/PID/数据库目录。
- 增加已设置数据库缺失或损坏时的 fail-closed 恢复状态，禁止自动建空库、状态
  true→false 降级或重新开放首次管理员设置。
- 增加每日自动备份、身份与 SHA sidecar、30 份轮转以及本机 UAC 原子恢复工具。
- 增加统一 API requestId/JSON 异常、双层登录限速、未知账号固定耗时校验、会话
  空闲/绝对时限、登录与系统安全审计。
- 增加预约变更时间线、分页、真实系统健康、公开大屏 stale/offline；进行中预约可由
  本人或管理员取消，但不能修改。
- 增加依赖哈希锁、SBOM、许可证和 runtime 来源证明门禁；没有 Authenticode 证书
  时保持正式外发关闭。
- 将冻结的全局视觉样式按功能域拆分为有序 CSS 清单，并以源码和生产产物 SHA
  保证拆分不改变现有视觉、选择器或层叠行为。

> 真实 Windows UAC、SmartScreen/EDR、计划任务重启、局域网第二台设备和大屏长时间验收完成前，本版本只允许标记为候选版。
