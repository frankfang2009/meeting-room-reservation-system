# 更新记录

## V2.0.0（候选版）

- 建立与 V1 完全隔离的 fresh-install 产品代际。
- 使用 React 冻结视觉稿、Flask JSON API、SQLite 与同源桌面局域网部署。
- 提供全单位共享预约日历、本人/管理员分级管理、修改与取消、revision 并发保护和追加式预约事件。
- 提供预约记录、网页提醒、全局/个人标签、用户偏好、笔录室与用户管理。
- 提供独立的临近预约与他人变更通知，确认回执按类型和 revision 隔离。
- 提供服务端白名单和姓名脱敏的公开局域网大屏。
- 提供首次本机配置、系统状态、诊断、备份和只读集成令牌。
- 提供带安装身份的安全启停、Windows 只读 PID 探测、RFC1918 局域网地址与轮转运行日志。
- 新建 V2 全新安装事务与后续 V2-only 累计升级的非生产安全基线，不迁移或删除
  V1 数据；V2.0.0 不宣称支持在线升级。
- Claude 独立复核后加固正式安装基线：固定 Program Files、显式 Windows DACL、
  SYSTEM 运行时模块白名单和受保护的 secret/PID/数据库目录。
- 增加已设置数据库缺失或损坏时的 fail-closed 恢复状态，禁止自动建空库、状态
  true→false 降级或重新开放首次管理员设置。
- 增加每日自动备份、身份与 SHA sidecar、30 份轮转以及本机 UAC 原子恢复工具。
- 增加统一 API requestId/JSON 异常、双层登录限速、未知账号固定耗时校验、会话
  空闲/绝对时限、登录与系统安全审计。
- 增加预约变更时间线、分页、真实系统健康、公开大屏 stale/offline；进行中预约可由
  本人或管理员取消，但不能修改。
- 增加依赖哈希锁、SBOM、许可证和 runtime 来源证明门禁；没有 Authenticode 证书
  时保持正式外发关闭。

> 真实 Windows UAC、SmartScreen/EDR、计划任务重启、局域网第二台设备和大屏长时间验收完成前，本版本只允许标记为候选版。
