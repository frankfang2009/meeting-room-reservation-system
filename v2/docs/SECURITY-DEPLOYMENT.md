# V2.2.3 安全部署边界

本文记录 V2.2.3 在没有 TLS 与 Authenticode 证书时允许部署的最小安全条件。
任一条件不能满足时，不应把候选版交给真实用户。

## 网络

- 仅部署在由单位管理的 Windows Domain/Private 网络；防火墙只开放 TCP 8080 到
  `LocalSubnet`。
- 禁止路由器端口映射、公网反向代理、访客 Wi-Fi、不受控 VPN 与跨互联网访问。
- HTTP 不提供传输加密。部署方必须用 VLAN、受管终端、交换网络访问控制与物理
  办公环境限制抓包和中间人风险。
- 首次设置前只允许安装机通过 `127.0.0.1:8080` 访问；完成设置并安全重启后才能
  监听局域网。首次设置页面不得改用自定义域名；服务会拒绝固定 8080 端口以外及
  非 `localhost`/回环 IP 的 Host。

## Windows 主机

- 正式路径固定为 `%ProgramFiles%\会议室预约系统V2`，不得移动到桌面、Public、
  用户目录、共享盘或可移动介质。
- 普通用户只可读取和执行程序；数据库、secret、PID、日志和备份只允许 SYSTEM
  与 Administrators 访问。
- 不得关闭 UAC、Windows 防火墙、SmartScreen、EDR 或 AppLocker 来绕过安装失败。
- 后台任务以 SYSTEM 运行，因此任何 ACL 或 Python 模块路径校验失败都必须先修复，
  不能通过放宽目录权限继续运行。

## 身份与会话

- 首次管理员密码不得复用 Windows 登录密码，并应通过单位的离线安全渠道保存。
- 共用电脑使用完毕必须点击“退出登录”；空闲 30 分钟或累计 12 小时后会话自动失效。
- 连续登录失败或密码喷洒会触发限速。不得为排障关闭限速或 CSRF。
- 停用账号、重置密码、修改角色后，旧会话必须立即失效。

## 备份与恢复

- 每天检查系统状态页中的最近成功备份；每日 02:00 任务按本地日历日执行，服务
  启动时发现超过 24 小时未成功会补做。维护锁只有在安装身份与进程身份均可核验
  且原进程已经结束时才会自动回收。
- 备份目录同样包含敏感个人信息，不得复制到个人网盘、聊天软件或未加密 U 盘。
- 恢复只能在安装机本地运行 UAC 提权的“⑥ 从备份恢复”；不得接受网页上传的
  数据库或其他安装身份的备份。
- 数据库缺失、损坏或身份不一致时，系统应保持 fail-closed；禁止删除
  `install.json`、伪造空数据库或重新运行首次设置来“修复”。

## 安装包来源

- 没有 Authenticode 签名时，候选包只能从受控内部渠道取得，并通过另一个可信
  渠道核对发布方提供的 SHA-256。
- 解压后若杀毒软件、SmartScreen 或组策略拦截，应保存诊断结果交给维护人员；不得
  关闭安全软件。
- 依赖锁、SBOM、第三方许可证、runtime 来源与构建树哈希必须随正式候选归档。
