3. 修复版必须提升为 V2.5.2，重新生成安装包、SHA 和候选证据；不得覆盖或重打 V2.5.1。
4. V2.5.2 至少重测原失败项、相邻功能，以及 T01–T08 全部快速复测项。
5. Windows 普通用户物理门禁和 Authenticode 签名完成前，继续保持 `formal_external_release_allowed=false`，只走受控内部渠道。
