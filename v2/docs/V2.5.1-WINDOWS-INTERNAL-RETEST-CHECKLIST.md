## 1. 测试规则

1. 只在无客户数据的 Windows 测试机执行，全部使用明显的合成账号和业务数据。
2. 不导入、读取、修改或删除 V1 数据。机器如已有 V2 安装，先停止并报告，不得用全新安装包覆盖。
3. 不得关闭 UAC、SmartScreen、Defender、EDR、防火墙或单位安全策略换取通过。
4. 每项填写 `PASS / FAIL / SKIP / BLOCKED`；`SKIP` 与 `BLOCKED` 不能计为通过。
5. 出现 FAIL 时先保留现场和脱敏证据，不自行修改程序、数据库、注册表、计划任务或防火墙。
6. 不提交客户数据库、完整日志、密码、secret、真实个人信息或未脱敏 IP。

## 13. 发现 Bug 后的版本规则

1. 全部必测项通过且无产品 Bug：继续使用当前 SHA 的 V2.5.1 包，不重新打包。
2. 只有环境问题：解决环境后复测；不得把 BLOCKED/SKIP 写成 PASS。
3. 发现产品 Bug：保留 V2.5.1 标签、Release 和现有 SHA 不变，在新分支修复并补自动化回归。
4. 修复版必须提升为 V2.5.2，重新生成安装包、SHA 和候选证据；不得覆盖、重打或冒充 V2.5.1。
5. V2.5.2 至少重测原失败项、相邻功能、T01–T12、T16–T18、T22–T24，以及真实重启后的局域网地址。
6. Windows 普通用户物理门禁和 Authenticode 签名完成前，继续保持 `formal_external_release_allowed=false`，只走受控内部渠道。
