适用于预约本人和管理员。系统按服务器时间判断当前阶段；不要用自己电脑的时钟推断“已开始”。

| 阶段 | 修改 | 取消 | 交接 |
| --- | --- | --- | --- |
| 开始前 | ✓ | ✓ | ✓ |
| 进行中（已开始未结束） | ✗ | ✓ | ✗ |
| 已结束 | ✗（完全只读） | ✗ | ✗ |

## 为什么这样设计

- **进行中不让改**：预约已经开始意味着当事人可能已在场，此时改时间或内容会让记录失真；确实要中止就取消。
- **已结束只读**：历史记录必须反映当时的事实，结束后的预约只作为档案存在。

尝试修改进行中的预约时，系统提示：

> 预约已经开始，不能再修改。如需停止，请返回详情取消预约。

「已结束」不是一个需要操作的状态：它表示有效预约的时间已经过去，记录自动进入历史，无需任何确认动作。

## 如果按钮不见了

- 预约已开始：关闭编辑，回到详情；确需停止时选择「取消预约」；
- 预约已结束或已取消：详情只读，不能再次修改；
- 你不是预约本人且不是管理员：没有修改/取消权限。

完成取消时会出现「预约已取消」，时段重新开放；若看不到该确认，先不要重复提交，按 [[tr-save-fail|保存预约失败的排查方法]] 处理。
