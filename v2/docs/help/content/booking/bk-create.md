适用于已登录的员工和管理员。先在「预约日历」选择一个空白时段，再填写表单；表单中的标签也必须选定。

## 填写内容

| 字段 | 必填 | 上限 |
| --- | --- | --- |
| 预约对象 | 是 | 120 字 |
| 案号 | 是 | 120 字 |
| 事项 | 是 | 120 字 |
| 标签 | 是 | 从当前可用标签中选 1 个 |
| 备注 | 否 | 500 字 |

时长为 30–180 分钟、按 30 分钟递增；开始时间自动对齐整点或半点。

## 时间规则

- 必须落在工作时间之内（由管理员设置，例如 08:30–17:30）；
- 不能创建已经开始的时段——页面会提示选择当前时间之后的空白时段；
- 日期可浏览范围为业务日前后两年。

## 保存时会发生什么

- 时段空闲：预约立即生效，日历上显示你的姓名和案号；
- 时段刚被占用：弹出「预约刚被别人占用」，你的草稿完整保留，换时段续用即可；
- 网络或服务异常：显示「保存失败」「重试保存」，内容同样不丢。

## 完成标志

保存成功后表单关闭，出现「预约已创建」，日历重新读取并显示预约块。只看到表单仍打开或只有加载状态时，不要把预约当作已创建。

## 保存前的隐私提醒

有效预约详情对登录员工共享；当事人、案号、事项和备注只填写办理所需信息。需要了解可见范围时，先看 [[bk-visibility]]。

## 小技巧

在「个人中心 → 新建预约默认值」展开后设置默认时长、默认笔录室和默认标签，之后新建空白预约单会自动预选。
