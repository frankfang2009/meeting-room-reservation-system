**用户名不能改，姓名可以改。**两者是不同的东西：

| | 用户名 | 姓名 |
| --- | --- | --- |
| 用途 | 登录凭证 | 界面显示 |
| 规则 | 3–80 个字符、不含空格、创建后**不可修改** | 最长 80 字，随时在「个人中心」修改 |
| 唯一性 | 全单位唯一 | **允许重名** |

## 改名的影响范围

改姓名只影响之后新建或之后重新保存的业务显示；已保存预约保留当时的预约人姓名快照，不追溯改写历史。

## 重名怎么区分

系统允许员工重名。区分靠**用户名 + 所属部门**：交接选择人时显示“姓名 + 部门”，用户管理里可按姓名、用户名或部门搜索。
