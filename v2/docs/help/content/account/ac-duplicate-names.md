**能。** 姓名只是显示信息，允许两位“王芳”同时存在；登录使用的是全单位唯一的用户名。

## 重名带来的实际体验

| 场景 | 表现 |
| --- | --- |
| 登录 | 各用各的用户名，互不影响 |
| 交接选择人 | 列表显示"姓名 + 部门"帮助区分 |
| 预约日历 | 显示预约者姓名——同名的两位看起来一样，看部门或问本人确认 |
| 用户管理 | 管理员可搜索姓名、用户名或部门 |
| 统计 | 数据中心按系统账户（用户）归集，不会互相算错 |

## 操作时怎么确认对象

建账号时填写部门，并在用户管理或交接选择人时同时核对姓名、部门和用户名。不要只凭日历上的显示姓名判断操作对象。
