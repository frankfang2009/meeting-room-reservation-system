单位标签（标签 1、2 槽）是全单位统一的业务口径，例如“工伤 / 非工伤”“首次 / 复查”。

## 设置路径

「预约日历」页 → 标签区打开编辑面板 → 「单位标签」栏（标注"全单位通用"）→ 修改 → 「保存单位标签」。

## 规则

- 最长 40 字；
- 只有管理员能改；员工在这一栏是只读的；
- 个人标签（3、4 槽）每位员工自己在「个人中心」维护，与你无关；
- **改名不改历史**：已有预约保留当时的标签文字快照，统计口径不漂移。

## 完成标志与建议

保存后重新打开标签区，确认新文字已显示。两个槽位就够用，克制是美德——先想清楚这两个标签要回答什么问题；改名不会改写旧预约的标签快照。
