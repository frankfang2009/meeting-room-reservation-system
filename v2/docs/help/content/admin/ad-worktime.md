适用于管理员。「系统状态」页点「工作时间」整行，右侧抽屉里修改开始/结束时间（按 30 分钟对齐，结束须晚于开始）。保存后回到状态页确认新值已显示。

## 影响范围

| 项 | 影响 |
| --- | --- |
| 之后的新预约 | 只能落在新工作时间内 |
| 日历时间轴 | 按新时间生成 |
| **已有预约** | **完全不动**——即使落在新工作时间之外，仍正常显示、正常办理 |

也就是说：把结束时间从 17:30 提前到 17:00，不会取消或移动任何 17:00–17:30 的既有预约；只是从现在起不能再新约那个时段。

## 典型场景

- 季节性作息调整（夏令/冬令）：直接改，历史无缝保留；
- 首次设置时填错了：随时可改，无需重装。

改动会记录 `settings.updated` 安全审计。新规则只影响之后的新预约，不要用它替代对已有预约的逐项调整。
