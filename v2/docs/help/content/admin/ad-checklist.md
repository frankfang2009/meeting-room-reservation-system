新部署完成后，管理员应走完一次“配置—员工验收—隐私验收—备份验收”闭环，再把系统地址发给全员。不要只以首次设置页面显示完成作为上线依据。

## 开始前准备

- 首名管理员的用户名和强密码，保存在单位认可的安全位置；
- 笔录室名称、排序和工作时间；
- 至少一个用于验收的普通员工账号；
- 一条已经确认、确需登记的真实工作预约；尚无真实安排时暂缓预约写入验收，不要向正式系统加入虚构当事人、案号或演示记录。

系统不提供默认账号或默认密码文件，也不会导入 V1 数据。

## 七步配置与验收

1. **完成首次设置。** 第一次从服务器本机打开系统，依次完成「安全说明 → 管理员 → 笔录室 → 工作时间 → 完成」，创建首名管理员和至少一间笔录室。
2. **确认服务已进入局域网模式。** 登录后到「系统状态」查看服务范围和局域网地址；用同一单位内网中的第二台电脑打开该地址。只在服务器本机能打开时，不要开始发放账号。
3. **建立普通员工账号。** 按 [[ad-create-user|如何新建用户并发初始密码？]] 创建验收账号，确认角色为普通员工，并通过可靠渠道单独告知用户名和初始密码。
4. **完成业务配置。** 按 [[ad-rooms|笔录室的添加、停用与删除]] 核对名称、排序和启用状态；在「预约日历」设置单位标签 1、2；到「系统状态 → 工作时间」确认可预约范围。
5. **用员工角色完成一次业务验收。** 在第二台电脑用员工账号登录，确认能看到共享日历，但看不到「笔录室」「用户管理」「系统状态」管理入口。有真实工作安排时，用该安排创建预约并确认日历出现预约块；尚无真实安排时，只检查界面和权限，不写入虚构记录。
6. **检查公开大屏隐私。** 在未登录窗口打开 `系统地址/display`，确认只显示房间、时间和脱敏访客姓名，不出现完整姓名、工作人员身份、案号、事项、备注或标签。涉密房间应先关闭「在公开大屏显示」再复查。
7. **完成首次备份。** 到「系统状态 → 最近备份」点「立即备份」。等待页面显示备份成功，并确认状态从「待备份」变为「已追平」；备份边界见 [[ad-backup|备份策略全解]]。

## 完成后自检

- 第二台内网电脑可以通过局域网地址登录；
- 普通员工只能管理本人预约，管理员仍能管理用户、笔录室和系统；
- 工作时间、房间顺序和单位标签与实际安排一致；
- 公开大屏只显示允许字段，涉密房间不进入投影；
- 最近备份显示「已追平」。

满足以上五项后，再从「系统状态」复制局域网地址并发给全员。

## 遇到这些情况先停止

- 完成首次设置后又出现首次设置页面；
- 页面显示「系统需要恢复」；
- 只有服务器本机能访问，第二台内网电脑无法打开；
- 首次备份失败或一直不能达到「已追平」。

不要删除数据目录、重新初始化或反复安装覆盖。记录页面提示原文、发生时间和请求编号，交给维护人员处理；不要发送数据库、备份、密码或含真实业务内容的截图。
