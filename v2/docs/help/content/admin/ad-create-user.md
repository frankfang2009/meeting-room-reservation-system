适用于管理员。进入「用户管理 → 新建用户」，填写后先核对用户名、姓名、部门和角色，再保存：

| 字段 | 规则 |
| --- | --- |
| 用户名 | 3–80 个字符、不含空格、**创建后不可修改**、全单位唯一 |
| 姓名 | 最长 80 字，允许重名 |
| 所属部门 | 最长 120 字，用于区分同名同事 |
| 初始密码 | 8–256 个字符 |
| 角色 | 管理员（可管理用户、笔录室与全单位预约）/ 普通员工（仅管理本人的预约与偏好） |

## 发放纪律

- 初始密码通过**可靠渠道**单独告知本人，不要群发、不要写进共享文档；
- 提醒员工首次登录后核对个人信息；系统没有自助改密，员工想换密码也是找你重置；
- 建用户名时带上可区分的部分（尤其同名同事），部门字段尽量填全。

## 完成标志与异常

保存成功后返回用户列表，新用户显示为启用状态。若用户名重复、密码不符合长度或最后一名管理员保护被触发，按字段提示修改；不要为了“先建出来”而共享已有账号。

## 用户名与姓名的区别

用户名是登录凭证，不可改；姓名是显示名，员工可在「个人中心」自行修改。详见「用户名能改吗」。
