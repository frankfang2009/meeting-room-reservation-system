等候区的公开大屏（`系统地址/display`，无需登录）只投影被允许公开的启用房间。个别房间涉密时，可将其移出：

**「笔录室 → 编辑房间 → 关闭「在公开大屏显示」**。

## 这个开关的精确边界

| 影响 | 不影响 |
| --- | --- |
| 该房间及其预约**完全不出现在大屏响应里**（服务端就不输出，不是前端遮盖） | 员工登录后的预约日历照常可见、照常可约 |
| 全部房间都关闭时，大屏显示空列表 | 只读集成接口照常返回该房间 |

## 大屏本来就不显示的敏感信息

完整姓名、工作人员身份、案号、用途、备注、标签、电话、部门——大屏只有当前/下一时段和脱敏姓名（如"张\*燕"），脱敏规则详见「公开大屏的姓名是怎么脱敏的」。

> 大屏仅接受单位内网和服务器本机的访问，公网访问不到。

保存后打开 `/display` 检查该房间是否从名单消失；登录后的共享日历仍应保留该房间和已有预约。只在大屏消失，不代表预约已取消。
