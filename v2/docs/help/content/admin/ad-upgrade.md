升级由**维护人员**执行，管理员不要把帮助页中的操作当作自行安装授权；这里说明的是你会看到的现象和停止边界。

## macOS 版

- 服务启动时会做自动周期检查；距离上次尝试不足 24 小时就跳过；
- 管理员手动点「系统状态 → 软件更新 → 检查更新」时，两次手动检查至少间隔 60 秒；
- 有新版本时显示「有新版本 X · 查看发布页」，点链接跳转发布页下载；
- **只提示，绝不自动下载或自动安装**；检查请求不携带任何本机数据；
- 升级方式由维护人员按当前发布清单执行；必须先备份并确认数据目录、备份目录和日志目录不被覆盖。

## Windows 版

- 没有在线更新检查（界面上也没有这一行）；
- 升级由维护人员用已批准的升级包在服务器电脑上执行；安装包和 Windows 实机验收状态以发布清单为准，不把候选包当作正式分发依据；
- 升级期间服务短暂停止，员工页面会显示连接异常，属预期。

## 升级前后

- 升级前自动/手动备份是维护人员的流程要求；
- 升级后由维护人员在「系统状态」确认「程序版本」和「最近备份」，再让员工重新打开页面；
- 若员工仍看到连接异常，不要让多人反复提交，先确认服务已恢复。
