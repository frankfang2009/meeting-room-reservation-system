「系统状态」是管理员的仪表盘，标题写着"查看本机服务、局域网连接与安全审计"。

## 运行环境各行含义

| 行 | 含义 |
| --- | --- |
| 程序版本 | 当前软件版本；有新版本时旁边出现角标（仅 macOS 版） |
| 数据库版本 | 当前数据结构版本（只读信息） |
| **局域网地址** | 员工浏览器要访问的地址；点「复制」即可发给全员 |
| 服务端口 | 固定 8080 |
| 服务范围 | 局域网 / 仅本机（首次设置完成前只绑本机） |
| 数据序号 / 备份序号 | 数据与备份的进度对照（备份序号落后=待备份） |
| 软件更新 | 仅 macOS 版显示：手动「检查更新」 |
| 工作时间 | 点整行打开修改抽屉 |
| 最近备份 | 已追平 / 待备份 / 尚无备份，点整行查看详情并可「立即备份」 |

## 两个按钮

- 「立即刷新」：重新读取全部状态；
- 「导出诊断信息」：生成**脱敏**诊断文件（不含预约内容和凭据），只通过单位授权渠道交给维护人员。

## 安全审计

下方「安全审计」默认收起，但后台仍持续刷新；标题会显示“已同步”或新记录数量。点标题展开后可查看登录、预约、管理和系统操作（谁、何时、做了什么、结果），并按操作类型、对象、人员、日期筛选。不要把筛选能力理解为永久保留承诺；登录失败记录有单独的有界聚合，保留边界见 [[sec-audit]]。

## 接口令牌（进阶）

用于只读的局域网集成对接（如电子屏第三方系统查房间/时段）。该区默认收起，标题显示令牌数量；日常用不到可忽略。展开后仍可新建或撤销，令牌明文只在创建时显示一次。
