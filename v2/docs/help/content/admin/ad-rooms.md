适用于管理员。「笔录室」页以卡片展示每间房：启用状态、今天/未来场次、下一场安排。右上「添加笔录室」新建。

## 每间房间的设置

| 设置 | 说明 |
| --- | --- |
| 名称 | 最长 80 字；叫"会议室""接待室"都可以 |
| 排序号 | 数字越小，在预约日历中越靠前（1–10000） |
| 在预约日历中启用 | 停用后从日历隐藏，**已有预约不会自动取消** |
| 在公开大屏显示 | 关闭后不进入等候区大屏投影（详见「涉密房间」一文） |

## 停用 vs 删除

- **停用**（推荐）：房间暂时不可约，历史完整保留，随时可重新启用；
- **删除**：存在**未结束的有效预约**时会被阻断，提示「需要先处理预约」——只有已取消或已全部结束的房间才能删。即便可删，一般也建议停用，保留历史完整性。

## 保存后的检查

保存房间后回到卡片列表，确认名称、启用状态和公开大屏开关符合预期；删除前必须在确认页再次核对房间名。

## 注意

停用房间前，先处理它名下未来的预约（取消或由管理员改到其他房间）：停用只是隐藏日历入口，已有预约仍保留，不会自动取消。
