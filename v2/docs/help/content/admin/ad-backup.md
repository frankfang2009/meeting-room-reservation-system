备份由服务维护流程执行，管理员需要知道三件事：**计划何时检查、什么时候该手动做、恢复时找谁**。

## 自动备份

| 项 | 规则 |
| --- | --- |
| 时间 | 每天凌晨 02:00（按服务器本地日历日） |
| 补做 | 服务启动时检查是否需要补做；距上次有效备份不足 24 小时不会重复补做 |
| 保留 | 最近 **30 份**校验通过的备份，自动轮转 |
| 位置 | 只保存在服务器电脑上，不离开本单位 |

## 手动备份

「系统状态 → 最近备份」行显示状态（**已追平 / 待备份 / 尚无备份**），需要时点「立即备份」。备份完成后重新读取该行，确认状态回到「已追平」。建议在这些操作后手动做一次：

- 批量调整（改用户、改房间、改标签）之后；
- 大版本升级之前；
- 任何"改完心里不踏实"的时刻。

## 恢复

恢复**不在网页里做**：需要维护人员在服务器电脑上用管理员权限的恢复工具执行。页面出现「系统需要恢复」时，按提示记下恢复代码和请求编号，联系维护人员即可——每天自动备份就是为这一刻准备的。

> 「导出诊断信息」是脱敏文件，不含预约内容和凭据；仍应只通过单位授权渠道提供给维护人员。
