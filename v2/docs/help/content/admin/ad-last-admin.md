你正在操作的是**最后一名启用的管理员**。系统强制保留至少一名启用管理员，防止全员被锁在系统外。此时：

- 角色单选被锁定，不能改成普通员工；
- 「启用账户」开关被锁定，不能停用；
- 页面提示：

> 当前账户是最后一名启用管理员——请先启用或创建另一名管理员，再更改角色或停用。

## 解除办法

先「新建用户」创建另一名管理员（或把某位停用的管理员重新启用），重新读取用户列表确认已有两名启用管理员，再回头处理这位。

## 建议

单位至少保持**两名**启用管理员：一人休假、离职或忘密码时，另一个人能进系统处理。
