**会，立即。** 管理员保存重置结果后：

- 该用户的旧密码作废（弹窗提示「保存后旧密码立即失效」）；
- 该用户**所有已登录的会话立即失效**，包括别人正在用的浏览器——他会被要求用新密码重新登录。

## 操作路径

「用户管理 → 编辑用户 → 重置密码 → 为某人设置新密码」，输入新密码（8–256 字符）后「确认重置」。

## 这其实是安全特性

- 怀疑账号异常：重置密码即可立即收回所有访问权，不用等会话自然过期；
- 停用账户同样立即生效（停用后无法登录，历史记录保留）。

## 完成标志与提醒

保存后让本人用新密码重新登录确认；重置前先跟本人打好招呼，避免他在填表途中被登出。草稿是否恢复受同一标签页和账号限制，参见 [[ac-logged-out]]。
