当一场**还没开始**的有效预约需要换人办理时，用工作交接把预约转给同事：请假、临时分工、岗位调整。先确认目标同事账号仍启用、预约尚未开始。交接完成后：

- 预约转入接手人名下，日历显示接手人姓名；
- 工作量统计归接手人；
- 原归属轨迹完整保留在「变更记录」时间线里（A→B 可追溯）。

## 适用条件

| 条件 | 说明 |
| --- | --- |
| 预约状态 | 有效（未取消） |
| 预约进度 | 尚未开始（已开始的预约不能交接） |
| 接手人 | 任一**启用**状态的同事（不能是自己） |
| 同时进行的请求 | 一场预约同一时间只能有一个待处理请求 |

## 两种方式选哪种

| | 普通交接（任何人可发起本人预约） | 管理员指派 |
| --- | --- | --- |
| 是否需要对方确认 | 需要 | 不需要，立即生效 |
| 适用场景 | 正常协商换人 | 联系不上人、应急兜底 |

## 完成标志

普通交接只有对方点「接受交接」后才改变预约人；在此之前，原预约者仍负责这场预约。需要立即换人且无需对方确认时，管理员才使用「指派给同事」，详见 [[ho-admin-assign]]。
