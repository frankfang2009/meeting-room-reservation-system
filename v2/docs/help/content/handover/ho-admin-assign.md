两者都改变预约归属，但生效方式不同。两种方式都只适用于有效且尚未开始的预约；目标用户必须仍处于启用状态。

| | 普通交接（员工发起） | 管理员指派 |
| --- | --- | --- |
| 按钮 | 「交接给同事」 | 「指派给同事」（管理员看他人预约时） |
| 对方确认 | 必须接受才生效 | **立即生效，无需确认** |
| 结果通知 | 弹窗可接受/不接受 | 结果通知只能「查看预约」或「我知道了」 |
| 待处理请求 | 一次一个 | 指派同时自动撤回该预约旧的待处理请求 |

## 完成标志

普通交接要等对方明确选择；管理员指派成功后，详情中的预约人立即变为目标用户，目标用户下次页面轮询会看到结果通知。

## 被指派人会看到什么

一条不可拒绝的结果通知，明确说明预约已转入你名下、无需接受；点「我知道了」只代表知晓，不再改变归属。

## 两条防误规则

- 管理员把预约指派给自己，不产生多余通知；
- 连续重指派时，只有最新预约者收到结果通知，不会出现旧通知错误地声称"预约还在某人名下"。

如果目标用户刚被停用，先不要把旧页面中的名字当作可指派成功；管理员应重新读取用户和预约列表，并按 [[ad-disable-user|停用账号后的未来预约检查]] 处理。

## 定位

指派是**兜底手段**：联系不上人、必须立即调整时用。日常换人请走普通交接，让接手人有知情和拒绝的机会。
