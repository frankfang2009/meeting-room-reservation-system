提示音设置默认开启，界面文案是「临近提醒与到达提醒到达时播放一声温和的轻提示」。当前可由代码确认的触发点是：一场新的临近预约首次进入提醒窗口时播放一次提示音。预约变更通知不承诺播放提示音；真实浏览器音频仍需 R3 复核。

## 开关位置与完成标志

先在「个人中心 → 通知」开启「预约提醒」，再在展开的提醒详情里找到「提醒提示音」。开关描述为“临近提醒与到达提醒到达时播放一声温和的轻提示”。关闭预约提醒只收起这些细项，不清除已选提前量或声音偏好；保存成功后状态保持即表示设置已保存。

## 听不到声音时按顺序检查

1. 开关是否开着（个人中心）；
2. 浏览器标签页是否被静音（右键标签页可查看）；
3. 系统音量和浏览器播放权限；
4. 提醒是否真的进入窗口（看日历角标或「我的预约」徽章是否出现）。

> 提示音只在一场新的临近预约**首次进入提醒窗口**时播放一次，不会反复响；错过那一声就看日历角标和「我的预约」徽章。浏览器后台节流、标签页静音和系统音量需要真实设备确认。
