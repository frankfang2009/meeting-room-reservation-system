因为临近提醒由当前浏览器页面读取并展示。关闭页面后，系统不会在后台替你发送短信、微信、邮件或系统通知。

## 怎样可靠地使用提醒

1. 登录后保留一个系统标签页，不要在预约开始前关闭整个浏览器。
2. 在「个人中心 → 通知」开启「预约提醒」，再在展开的详情中选择提前 15、30 或 60 分钟。
3. 如需声音，在同一展开区开启「提醒提示音」，并确认电脑和浏览器没有静音。
4. 切回系统标签页时看「今天」和「我的预约」徽章；页面会立即重新检查当前提醒状态。

页面打开期间通常每 60 秒检查一次。预约进入提前窗口后，日历预约块出现倒计时角标，左侧「我的预约」显示数量，首次进入窗口时出现一次轻提示；这些提醒不需要确认。界面表现见 [[rm-how|预约快开始了，系统怎么提醒我？]]。

## 页面关闭时不会发生什么

- 不会发送短信、微信、邮件或系统原生通知；
- 不会替你通知当事人；
- 不会因为页面关闭而改变、取消或错过这场预约本身；
- 重新打开并登录后，只会按当时的时间重新计算仍在提醒窗口内的预约。

经常离开电脑时，重要场次请同时使用单位认可的日程或闹钟。给当事人的提醒需要从预约详情点「复制提醒信息」，再由你自行发送；系统不记录“已经发送”。操作方法见 [[rm-party-notify|如何给当事人发提醒？]]。

交接请求不受「预约提醒」和「预约变更」两个开关影响，但同样需要页面打开后才能在系统中看到。
