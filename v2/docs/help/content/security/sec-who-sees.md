按数据类型分。先记住：有效预约日历是共享空间，公开大屏是另一套脱敏投影。

| 数据 | 谁能看到 |
| --- | --- |
| 有效预约的完整详情（当事人、案号、事项、备注、标签） | **全体登录员工**（共享日历的设计） |
| 已取消的预约 | 仅预约本人和管理员 |
| 变更记录时间线 | 仅预约本人和管理员 |
| 预约记录（历史） | 员工仅本人；管理员全单位 |
| 数据中心统计 | 员工仅本人；管理员全单位/指定人员 |
| 员工目录 | 任何登录用户可见姓名+部门（**不含用户名**） |
| 公开大屏（无需登录） | 只显示笔录室、日期/时段、脱敏姓名、连接状态等白名单信息；不显示案号、用途、备注、标签或员工身份 |
| 安全审计 | 仅管理员 |

## 为什么有效预约全员可见

同事之间需要避让时段、了解"这个当事人在谁手上"。这是共享日历类工具的通行设计，也是它比纸质登记本先进的地方。

## 实用建议

全员可见意味着填写内容请把握敏感尺度；备注也会进入有效预约详情和导出范围，确实敏感的表述不要写入预约字段，按单位授权流程线下处理。
