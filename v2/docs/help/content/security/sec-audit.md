系统的安全审计记录**谁、在什么时间、做了什么、结果如何**，覆盖：

| 类别 | 示例 |
| --- | --- |
| 登录 | 登录成功/失败、退出、会话过期（含原因：空闲超时/时限已到/尝试过于频繁） |
| 预约 | 创建、修改、取消、交接、指派 |
| 管理 | 用户增改、密码重置、笔录室增改删、标签、工作时间、备份、CSV 导出 |
| 系统 | 首次设置、恢复相关 |

## 保留与查看

- 业务操作审计没有在当前管理员页面提供期限设置；登录失败记录使用有界聚合，不能承诺所有审计事件永久保留；
- 管理员在「系统状态 → 安全审计」查看；该区默认收起但后台持续刷新，标题会提示新记录，展开后可按操作类型、对象、人员、日期筛选；
- 普通员工看不到审计；审计以操作事实为主，部分事件会记录对象标识和筛选范围，不应把它当作预约明细备份。

## 一个细节

CSV 导出（包括超限失败）也会留痕 `report.csv_exported`——谁在什么时间、以什么范围和结果导出过办件明细，事后可按审计筛选查看。
