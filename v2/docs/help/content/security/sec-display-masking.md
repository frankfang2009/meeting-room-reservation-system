公开大屏只显示**服务端脱敏后**的姓名（浏览器响应中没有完整姓名）。当前规则：

| 姓名形态 | 大屏显示 | 示例 |
| --- | --- | --- |
| 单字或为空 | 访客 | — |
| 含非汉字字符 | 首字符 + \*\*\* | W\*\*\* |
| 复姓且三字以上 | 复姓 + \* | 欧阳\* |
| 两字姓名 | 首字 + \* | 张\* |
| 三字及以上 | 首 + \* + 末 | 张\*燕 |

## 大屏上不会出现的信息

完整姓名、工作人员身份、案号、用途、备注、标签、电话、部门——这些字段不进入当前大屏响应。

## 三条边界

- 大屏无需登录，但**只接受单位内网和服务器本机**的访问；
- 个别房间可在「笔录室」里关闭「在公开大屏显示」，整体移出投影；
- 大屏每 30 秒自动请求；连续 45 秒没有成功获取数据显示“数据可能已过期”，连续 90 秒显示“网络已断开”。可能保留最后一次成功获取的脱敏名单。

这些是页面状态阈值，不是预约有效性的判断。需要核对真实当前预约时，登录系统查看日历。
