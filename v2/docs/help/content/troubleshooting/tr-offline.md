本文说的是公开大屏（`/display`）上的状态，不等同于登录后的预约表单。大屏会持续监测与服务器的连接：

| 状态 | 含义 |
| --- | --- |
| 数据过期 | 超过 45 秒没有成功刷新（网络抖动或服务忙） |
| 离线 | 超过 90 秒没有成功刷新（服务停止或网络断开） |

## 通常不用担心

- **短暂波动**：网络或服务器繁忙几秒到几十秒，恢复后数据自动更新，页面提示"连接已恢复，数据已更新"；
- **服务器重启/升级窗口**：维护时段出现离线属预期；维护人员确认服务恢复后再重试。

## 持续离线时

1. 问一句同事能不能用——只有你不行为网络问题；
2. 全员不行：服务器电脑或网络的问题，联系管理员（大概率是那台机器休眠了或服务未启动）。

> 如果页面显示“网络已断开”，可能保留最后一次成功获取的脱敏名单；它只是只读参考，不要据此判断当前预约状态。登录业务页无法访问时，转到 [[tr-cannot-open]]。
