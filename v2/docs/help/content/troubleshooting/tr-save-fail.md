看到「保存失败」时，先保持当前标签页和预约表单打开，不要刷新、关闭浏览器或换账号。界面会同时显示「未能保存本次修改，你填写的内容已保留」，并提供「重试保存」。

## 按你看到的提示处理

| 你看到的情况 | 处理方法 | 完成标志 |
| --- | --- | --- |
| 页面显示网络或服务错误 | 等页面恢复连接，再点「重试保存」；等待期间不要重复点击；持续异常见 [[tr-cannot-open|打不开系统页面]] | 表单关闭，出现「预约已创建」或「预约已更新」确认条 |
| 「预约刚被别人占用」 | 按 [[bk-conflict|草稿保留流程]] 返回日历，在新空白时段续用草稿 | 新时段出现预约块 |
| 「预约内容已发生变化」 | 按 [[bk-concurrent|并发修改处理方法]] 比较“你的修改”和“最新预约” | 保存后出现「预约已更新」确认条 |
| 字段下方有红色提示 | 按提示逐项修改；系统会把焦点移到第一个需要处理的字段 | 错误提示消失，提交后出现确认条 |

## 什么时候停止重试

出现以下任一情况时，不要继续重复提交：

- 连接长时间没有恢复，或同事也无法保存；
- 「重试保存」连续返回相同错误；
- 页面出现「系统需要恢复」；
- 你无法判断“最新预约”和本地修改哪一份应保留。

保持原标签页打开并联系管理员。提供：发生时间、所在页面、操作是创建还是修改、提示原文，以及页面显示的请求编号（如果有）。不要发送密码，也不要把包含当事人、案号或备注的完整截图发到单位授权范围之外。

如果必须在另一台电脑验证连接，只检查能否打开和登录，不要在那里重建同一场预约；另一台电脑看不到原标签页中尚未保存的草稿。
