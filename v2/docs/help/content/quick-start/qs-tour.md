登录后，左侧图标栏是主导航，底部头像打开「个人中心」。点左上角星形图标可回到「我的预约」。

## 全员可见的页面

| 页面 | 用途 |
| --- | --- |
| 我的预约 | 登录后的落脚页；显示你最近的一场预约和后续安排，可按笔录室、标签筛选 |
| 预约日历 | 主工作区：全单位共享的时段网格，创建预约都在这里 |
| 工作交接 | 「待我确认」和「我发起的」两类交接请求；有待处理时导航图标出现数量徽章 |
| 预约记录 | 历史预约按月列表，支持搜索案号、当事人、笔录室和标签 |
| 数据中心 | 个人（或全单位）工作量统计与 CSV 导出 |
| 个人中心（头像） | 个人资料、新建预约默认值、标签、通知开关；低频使用习惯和对外提醒模板按需展开 |

## 仅管理员可见的页面

| 页面 | 用途 |
| --- | --- |
| 笔录室 | 房间的添加、排序、启停与公开大屏开关 |
| 用户管理 | 账号的创建、编辑、停用与密码重置 |
| 系统状态 | 服务运行状态、备份、工作时间；安全审计和只读接口令牌按需展开 |

## 找不到入口时

- 员工看不到「笔录室」「用户管理」「系统状态」是正常的权限结果；
- 管理员仍应先从业务页面完成预约，再进入管理页面处理设置；
- 日历页的标签编辑区分单位标签（1、2 槽）和个人标签（3、4 槽），详见 [[bk-tags]]。
