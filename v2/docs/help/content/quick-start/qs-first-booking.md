第一次预约只需要完成一件事：在「预约日历」选择空白时段，填写三项必填内容并提交。建议先用确认过的真实工作安排操作，不要为了练习写入虚构业务记录。

## 开始前确认

- 你已经登录，左侧能看到「预约日历」；
- 管理员已经启用至少一间笔录室；
- 你知道预约对象、案号和事项，并准备从当前标签中选择一个标签。

## 五步完成预约

1. 左侧导航点「预约日历」。
2. 用顶部箭头选择日期（「今天」按钮回到当天）。
3. 点击任意**空白时段**，右侧滑出「新建预约」。
4. 填写**预约对象、案号、事项**，选择一个标签，再确认笔录室、开始时间和时长；备注可不填。
5. 点「创建预约」。

字段上限、时间范围和标签规则见 [[bk-create|如何创建预约？]]。

## 怎样确认创建成功

右侧表单关闭，日历顶部出现「预约已创建」确认条；对应时段出现预约块，并显示预约者姓名和案号。点击确认条中的「查看」可以重新打开这场预约。

创建后，这个时段立即对全单位显示为已占用；共享日历中的员工都能查看有效预约详情。

## 如果没有创建成功

- 看到字段下方提示：按提示修改，表单仍保持打开；
- 看到「预约刚被别人占用」：草稿已保留，按「时段被占了怎么办」换时段续用；
- 看到「保存失败」：保持当前标签页打开，不要刷新，按「保存预约失败怎么办」处理。

## 建议的下一步

在「个人中心 → 新建预约默认值」展开后设置默认时长、默认笔录室和默认标签。它们只预选以后打开的空白新建单，不覆盖编辑单或已保留的冲突草稿。
