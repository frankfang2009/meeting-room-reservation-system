账号由本单位管理员创建。系统没有自助注册，也不会通过短信或邮件发送账号；开始前请先从管理员处取得三项信息：**系统地址、用户名、初始密码**。

## 第一次登录

1. 打开浏览器（推荐 Edge 或 Chrome），访问管理员提供的系统地址。
2. 输入「用户名」和「密码」。用户名用于登录，不一定等于你的姓名。
3. 点「登录」。

## 登录成功的标志

页面会进入「我的预约」或「预约日历」，左侧出现系统导航，左下角显示当前账号。进入哪个首页由个人设置决定，不影响登录结果。

首次进入后建议：

- 到「个人中心」核对姓名和所属部门，不对就改；
- 在「个人中心 → 通知」确认提醒设置（默认开启，提前量默认 30 分钟）；
- 把系统保留为浏览器标签页——预约提醒只在页面打开时有效。

## 如果没有登录成功

| 你看到的情况 | 处理方法 |
| --- | --- |
| 「用户名或密码不正确，请重新输入。」 | 确认输入的是用户名而不是姓名，检查大小写和输入法；仍不正确请管理员重置密码 |
| 「尝试过于频繁」 | 停止重复尝试，等待几分钟后再输入正确凭据；详情见 [[ac-rate-limit|为什么提示「尝试过于频繁」？]] |
| 系统地址打不开 | 先确认电脑连接单位内网，再查看 [[tr-cannot-open|打不开系统页面]] |

不要把密码、含密码的截图或浏览器保存的凭据发给他人排查。

## 需要知道的规则

- 密码长度为 8–256 个字符；修改密码请找管理员重置，系统没有自助改密。
- 用户名创建后不可修改；姓名可以在个人中心修改，新姓名只用于之后的新预约，历史预约仍显示保存时的姓名。
- 同一账号 5 分钟内失败 8 次会暂时拒绝新的登录尝试；这不是永久锁定。
