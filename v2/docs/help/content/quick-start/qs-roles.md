系统只有两种角色，由管理员在「用户管理」中指定。先看你当前账号能做什么，再进入对应页面；员工不需要进入管理员页面。

| 能力 | 普通员工 | 管理员 |
| --- | --- | --- |
| 查看全单位预约日历与详情 | ✓ | ✓ |
| 创建预约、修改/取消本人预约 | ✓ | ✓ |
| 发起本人预约的交接 | ✓ | ✓ |
| 修改/取消他人预约 | ✗ | ✓ |
| 直接指派接手人（免对方确认） | ✗ | ✓ |
| 预约记录范围 | 仅本人 | 全单位，可按人筛选 |
| 数据中心范围 | 仅本人 | 全单位、本人或指定人员 |
| 管理用户、笔录室、工作时间、备份 | ✗ | ✓ |

## 两个补充说明

- 管理员不是"领导"概念，只是多了维护责任；日常预约两者用法完全相同。
- 系统始终保留至少一名启用的管理员，最后一个管理员的角色和停用开关会被锁定，防止全员锁死。

## 如果按钮和表格不一致

页面权限由服务器按当前账号判断。看不到某个入口时，先确认自己登录的是哪个用户名；不要借用他人账号。管理员需要代办他人预约时，应在预约详情使用管理员入口，并让操作人保留必要的业务依据。
