「数据中心」帮助复盘预约工作量。普通员工看到「我的数据」；管理员默认「全单位概览」，也可切换到本人或任意人员的个人视角。

| 指标 | 真实含义 | 常见误读 |
| --- | --- | --- |
| 有效预约 | 时间范围内未取消的预约场次 | 不是"办结数" |
| 已结束 | 有效且结束时间已过去的场次 | 不是独立状态，无需任何操作 |
| 总时长 | 全部有效预约的起止时长合计 | **不是实际办理耗时** |
| 取消 | 已取消的预约场次 | 不是取消率，也不表示工作质量 |

页面只显示取消场数，不显示取消率。取消率可以作为内部质量护栏参考，但不属于数据中心的用户界面，更不能作为考核口径。

## 图表的规则

- 趋势图：范围 ≤90 天按自然周展示，超过 90 天自动切换自然月；
- 可切换「场次 / 时长」两种指标；
- 筛选支持日期（最长 366 天）、笔录室、标签和关键词（最长 120 字）；
- 全单位页面展示时段、房间和单位标签分布，**不提供人员分布、人员排名或绩效分数**；要看单个员工，使用顶部下拉框切换到该人员的个人视角。

## 设计立场

预约记录反映的是“约了什么”，不是“干得好不好”。系统不提供绩效分数或排名，避免把预约数据误读成考核口径；时长也不是实际办理耗时。
