「数据中心」右上角点「导出 CSV」，选择记录状态（全部状态 / 仅有效 / 仅已取消），导出**当前日期、房间、标签、关键词和人员范围内**的办件明细。

## 导出的字段（顺序固定）

预约日期、开始时间、结束时间、预约时长（分钟）、笔录室、预约人、当事人、案号、事项、标签、备注、状态、创建时间、最后修改时间、取消时间。

## 必须知道的规则

- 单次上限 **20,000 行**；按钮会在预计超限时禁用，服务器也会拒绝超限请求并记录失败审计，请缩小日期范围或其他筛选范围后分次导出；
- 文件带 UTF-8 BOM，Excel 双击直接打开不乱码；行尾为 CRLF；
- 防公式注入：文本以 `=`、`+`、`-`、`@` 开头时会自动加单引号前缀；
- **CSV 含单位内部办件信息（当事人、案号），请按内部资料保管**，不要外发；
- 每次导出（含超限失败）都写入安全审计。

## 范围

员工只能导出本人数据；管理员按当前数据中心视角导出（全单位或指定人员）。
