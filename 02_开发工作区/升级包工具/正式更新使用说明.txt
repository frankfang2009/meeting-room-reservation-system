会议室预约系统 V1.0.3 候选更新
================================

这是一份 Windows 实机验收候选版，不代表已经正式外发或通过普通用户验收。

操作方法
--------

1. 请先让正在使用系统的同事保存当前操作。
2. 把收到的完整 ZIP 解压出来，不要只复制其中一个 BAT。
3. 双击顶层“更新到V1.0.3-候选版.bat”，不要使用旧“升级到V*.bat”。
4. Windows 询问是否允许管理员权限时，选择“是”。
5. 看到候选更新完成后，按提示回到原系统目录双击“① 启动系统.bat”。

顶层 BAT 不接收参数，也不承担 RunAs 提权。包内 Python 会先校验完整负载，
定位安装目录，再直接请求 Windows 管理员授权。

更新范围
--------

- 支持 V1.0.0、V1.0.1、干净 V1.0.2、V1.0.2-r1 修复后状态；
- 能收敛已知旧累计升级残留和未完成的 V1.0.2-r1 修复事务；
- 重复运行会重新核对完整程序与 runtime，不重复迁移数据；
- 目标提交前失败时恢复原程序或已校验的 V1.0.2 安全基线；
- data 全树始终按哈希核对，不覆盖 reservation.db、.secret_key、
  install_id、首次登录文件、局域网地址状态或未知客户文件；
- backups、logs 和不能确认的旧回滚证据保留在本机。

本候选版保持 SCHEMA_VERSION=1、MIGRATIONS=[]，不修改依赖或 runtime。

验收边界
--------

自动化测试不能替代普通用户在真实 Windows 电脑上的 UAC、SmartScreen、EDR、
中文与特殊路径、计划任务、启动和局域网访问验收。实机验收通过前不得把本 ZIP
作为正式版本外发，也不得据此写出“正式发布通过”的结论。
