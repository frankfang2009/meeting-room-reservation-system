会议室预约系统——最简单使用说明
================================

适用电脑：64 位 Windows 10 或 Windows 11


第一次只做 4 步
----------------

1. 把整个文件夹放到单位一台长期不关机的电脑的本地固定盘。
   建议放在 D 盘，例如：D:\会议室预约系统
   不要放共享盘、U 盘、移动硬盘或网盘同步目录。

2. 双击“① 启动系统.bat”。

3. 浏览器打开后，用户名填：admin
   初始密码在“_程序文件\data\首次登录账号密码.txt”里。

4. 登录后打开“管理后台 → 用户管理”，点 admin 后面的“编辑”，
   填写新密码并保存。系统会让你用新密码重新登录。


让同事使用
----------

黑色系统窗口会显示“同事访问”地址。
把这个地址发给同一局域网里的同事即可。
同事只需要浏览器，不需要安装任何东西。

请始终以管理员页面显示的当前地址为准。单位网络、路由器 DHCP、VPN 或网卡变化
都可能让地址改变：

- 地址没变：同事继续使用原链接。
- 地址变了：管理员页面会持续显示旧地址和新地址。先点“复制新地址”发给同事，
  确认已经通知后再关闭提醒。
- 旧地址可能立即无法打开；换到新地址后，浏览器可能要求同事重新登录一次，
  这是正常现象，预约数据不会因此变化。


以后怎么用
----------

- 手动启动：双击“① 启动系统.bat”。
- 手动停止：关闭标题为“会议室预约系统”的黑色窗口。
- 备份数据：双击“② 立即备份.bat”。
- 开机自动运行：只需运行一次“③ 设置开机自动启动.bat”。
- 暂停本次后台运行：双击“④ 停止本次后台系统.bat”。
- 不再开机自动运行：双击“⑤ 取消开机自动启动.bat”。


收到升级文件时
------------

1. 先让正在使用的同事保存当前页面上的操作。升级会短暂停止服务，
   恰好正在提交的预约可能需要在升级后刷新页面并重试。
2. 只使用维护人员发来的“升级到Vx.x.x.bat”，把它放在桌面后双击。
3. Windows 询问是否允许修改时，点“是”。升级包会自动找到程序、备份、升级、
   检查并恢复原来的运行状态，不需要手工复制数据库、迁移数据或改配置。
4. 如果电脑里有多套会议室预约系统，升级器不会自行猜测；请按提示明确选择
   正确的安装文件夹。不确定时先取消并联系维护人员。
5. 升级期间不要关机、重启或关闭窗口，看到“升级成功”后再关闭。
6. 成功窗口会说明当前版本、账号/会议室/预约数据已保留、系统是已恢复运行还是保持停止，
   以及“同事访问”地址未变、已变化或暂时无法确认。
7. 地址已变化时，复制新地址发给同事；同事打开新地址后可能需要重新登录。
8. 如果提示升级失败，请不要自己删除或覆盖任何文件，
   把“_程序文件\logs”文件夹交给维护人员。


必须记住
--------

- 整个文件夹要放在本地固定盘；不要放共享盘、U 盘或网盘同步目录。
- 设置开机自动启动后，不要移动或改名这个文件夹。
- 服务器电脑关机、休眠或断网时，同事无法使用。
- 数据都在“_程序文件\data”里，绝对不要删除。
- 最近 30 份手动备份在“_程序文件\backups”里。
- 不要把这个系统开放到互联网。
- 建议让单位网管给服务器电脑绑定固定局域网 IP。
- 使用 VPN、切换 Wi-Fi/网线、路由器 DHCP 重新分配地址或防火墙策略变化后，
  请重新核对管理员页面的当前地址，并让另一台同局域网电脑实际打开一次。
- 不要手工复制或替换 reservation.db；旧版本升级只使用维护人员提供的正式升级文件。


Windows 安全提示
----------------

- 管理员授权（UAC）是升级和设置开机启动所必需的；取消授权不会完成操作。
- 未签名的 BAT 可能被 SmartScreen、杀毒软件、EDR、AppLocker 或单位组策略拦截。
  不要为了运行而关闭安全软件；请先核对维护人员提供的文件名和 SHA-256，
  再让单位网管按本单位规则确认或放行。
- 自动测试不能代替真实 Windows 电脑上的 UAC、SmartScreen、计划任务、防火墙、
  VPN 和同事电脑访问验收。


打不开时
--------

1. 看服务器电脑有没有关机或休眠。
2. 看黑色系统窗口是否还在；如果用开机启动，双击“①”会直接打开浏览器。
3. 登录管理员账号，核对页面显示的当前“同事访问”地址，不要只用旧收藏夹。
4. 确认两台电脑在同一个单位局域网，并暂时排查 VPN、网卡和防火墙变化。
5. 仍然打不开，把“_程序文件\logs\server.log”交给维护人员。
