首次部署验收清单（给单位网管）
==============================

候选版本：V{version}（预约体验与累计升级）

请在正式发给全员前，用单位的 Windows 电脑做一次：

[ ] 文件夹位于本地固定盘，路径不要太深，路径可包含中文和空格
[ ] 共享盘、U 盘、移动硬盘及已识别的 OneDrive 同步目录会被明确拒绝或安全停止
[ ] 人工确认不在其他网盘或同步工具目录中；这类目录不属于支持范围，不能保证全部自动识别
[ ] 双击“① 启动系统.bat”能打开登录页
[ ] 重复双击“①”只会再次打开浏览器，不会启动第二套服务
[ ] 用随机初始密码登录，并成功修改 admin 密码
[ ] 另一台同局域网电脑能打开窗口显示的“同事访问”地址
[ ] 管理员页面显示当前“同事访问”地址，普通用户看不到地址管理提醒
[ ] 地址未变时不误报；模拟 IP 或端口变化后，管理员能看到旧地址和新地址
[ ] 地址变化提醒可复制新地址，确认已通知前持续存在，确认后才消失
[ ] 地址连续变化时提醒从最后确认地址直接指向当前地址，不丢失未通知状态
[ ] 同事改用新地址后可以重新登录，原账号、会议室和预约数据均不变
[ ] 新建、冲突拦截、取消预约均正常
[ ] 当前半小时显示“已开始”，更早空闲时段显示“已过期”，且都不能点击
[ ] 当前时间行显示“现在”，打开今日页面能定位到当前时间附近
[ ] 预约表单不会允许结束时间早于或等于开始时间
[ ] 用户和会议室的新增、编辑、停用/删除均正常
[ ] 双击“② 立即备份.bat”后只生成一个 .db 备份文件
[ ] “③ 设置开机自动启动.bat”通过 UAC，重启电脑后系统可访问
[ ] 开机重启后再次核对当前局域网地址；脚本不再承诺原地址一定可用
[ ] “④ 停止本次后台系统.bat”和“⑤ 取消开机自动启动.bat”符合提示
[ ] 单位防火墙/组策略拒绝时，已经由网管放行 TCP 8080（仅局域网）
[ ] 分别在不使用 VPN、连接单位 VPN 和切换网卡后核对地址提醒及同事访问
[ ] 在一份 V1.0.0 测试副本上双击“升级到V{version}.bat”，旧用户、会议室和预约均保留
[ ] 在一份 V1.0.1 测试副本上双击“升级到V{version}.bat”，旧数据和会话密钥均保留
[ ] 升级前正在运行时，升级后恢复运行；升级前已停止时，升级后保持停止
[ ] 升级成功摘要显示版本、数据已保留、最终运行状态和地址未变/已变/无法确认
[ ] 地址变化时成功窗口和管理员页面都能给出新地址，且不会修改预约数据
[ ] 升级短暂停机期间的在途页面能明确失败或超时，刷新后可以安全重试
[ ] 有两套有效安装时升级器不会猜目录；选错或取消都不会修改任一安装
[ ] 8080 端口被另一套程序占用时不会把它误判为本系统健康
[ ] 再次双击同一升级文件时只提示“无需升级”
[ ] 用内部故障测试包验证失败后程序与数据库都会自动恢复
[ ] 连续双击两个升级窗口时，第二个窗口只提示“升级正在进行”
[ ] 设置开机自启和未设置开机自启两种状态下，升级后运行状态都与升级前一致
[ ] 在 version_committed 状态中断后新增测试预约，再运行升级包只清理状态且保留新增预约
[ ] 升级事务中强杀或重启后，计划任务不会启动半升级程序；恢复后状态正确
[ ] 成功事务的完整数据快照已经安全清理；失败或未完成事务仍保留诊断证据
[ ] UAC 取消、SmartScreen、杀毒软件/EDR/AppLocker 和单位组策略拦截均按单位规则处理

本候选版必须通过本地自动测试及 GitHub Windows PowerShell 5.1 的成功升级、重复运行、
version_committed 数据保留和故障回滚测试；Windows 的 UAC、SmartScreen、杀毒软件/EDR、
AppLocker、计划任务、防火墙、VPN、DHCP 和真实同事电脑访问仍必须以本清单在单位
实机确认一次。
