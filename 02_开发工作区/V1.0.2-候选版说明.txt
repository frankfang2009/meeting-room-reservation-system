会议室预约系统 V1.0.2 候选版说明
================================

状态
----

V1.0.2 已完成本地自动化测试、桌面与手机宽度浏览器验收，并生成单文件累计
升级包及完整 Windows 候选目录。数据库结构版本仍为 1，不需要迁移。

本候选必须在 GitHub Windows PowerShell 5.1 自动化验证通过后，继续完成真实
Windows 10/11 实机人工验收；在此之前不得作为正式客户版本归档或发送。


用户可感知改进
--------------

- 当前半小时的空闲时段显示“已开始”，更早时段显示“已过期”，不能再误点预约。
- 今日页面标出“现在”并定位到当前工作时间附近，手机端优先保证当前行可见。
- 日期增加中文星期。
- 预约表单会自动排除无效时间；改变开始时间时，结束时间默认顺延 30 分钟。
- 成功和普通信息提示会自动收起，错误与警告继续保持可见。
- 静态资源带内容指纹，升级后浏览器不会继续使用旧样式或旧脚本。
- 预约结束时刻一到，前台与后台统一显示为“已完成”。

Windows 自动化与实机门槛
----------------------

GitHub Actions 必须对本候选所在提交直接运行并通过：

- V1.0.0 → V1.0.2 成功升级及重复运行；
- V1.0.1 → V1.0.2 成功升级及重复运行；
- 两种旧版本起点的故障回滚；
- version_committed 中断后的新增数据保护；
- 用户、会议室、预约、会话密钥、数据库结构和版本文件保持正确。

自动化通过后，仍须按“升级机制实施计划.md”和本地完整候选中的网管清单，
在真实 Windows 10/11 上验收 UAC、SmartScreen、计划任务、并发双击、文件占用、
强杀/断电恢复和局域网访问。实机验收通过后，才可建立 V1.0.2 正式归档并发送客户。

V1.0.0 正式归档和 V1.0.1 候选基线继续保持只读。
