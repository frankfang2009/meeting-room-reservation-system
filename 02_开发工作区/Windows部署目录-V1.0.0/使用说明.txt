会议室预约系统——最简单使用说明
================================

适用电脑：64 位 Windows 10 或 Windows 11


第一次只做 4 步
----------------

1. 把整个文件夹放到单位一台长期不关机的电脑上。
   建议放在 D 盘，例如：D:\会议室预约系统

2. 双击“① 启动系统.bat”。

3. 浏览器打开后，用户名填：admin
   初始密码在“_程序文件\data\首次登录账号密码.txt”里。

4. 登录后打开“管理后台 → 用户管理”，点 admin 后面的“编辑”，
   填写新密码并保存。系统会让你用新密码重新登录。


让同事使用
----------

黑色系统窗口会显示“同事访问”地址。
把这个地址发给同一局域网里的同事即可。
同事只需要浏览器，不需要安装任何东西。


以后怎么用
----------

- 手动启动：双击“① 启动系统.bat”。
- 手动停止：关闭标题为“会议室预约系统”的黑色窗口。
- 备份数据：双击“② 立即备份.bat”。
- 开机自动运行：只需运行一次“③ 设置开机自动启动.bat”。
- 暂停本次后台运行：双击“④ 停止本次后台系统.bat”。
- 不再开机自动运行：双击“⑤ 取消开机自动启动.bat”。


必须记住
--------

- 整个文件夹要放在本地固定盘；不要放共享盘、U 盘或网盘同步目录。
- 设置开机自动启动后，不要移动或改名这个文件夹。
- 服务器电脑关机、休眠或断网时，同事无法使用。
- 数据都在“_程序文件\data”里，绝对不要删除。
- 最近 30 份手动备份在“_程序文件\backups”里。
- 不要把这个系统开放到互联网。
- 建议让单位网管给服务器电脑绑定固定局域网 IP。
- 这是全新安装版，不要把旧项目的 reservation.db 直接复制进来。


打不开时
--------

1. 看服务器电脑有没有关机或休眠。
2. 看黑色系统窗口是否还在；如果用开机启动，双击“①”会直接打开浏览器。
3. 确认两台电脑在同一个单位局域网。
4. 仍然打不开，把“_程序文件\logs\server.log”交给维护人员。
