首次部署验收清单（给单位网管）
==============================

请在正式发给全员前，用单位的 Windows 电脑做一次：

[ ] 文件夹位于本地固定盘，路径不要太深，路径可包含中文和空格
[ ] 双击“① 启动系统.bat”能打开登录页
[ ] 重复双击“①”只会再次打开浏览器，不会启动第二套服务
[ ] 用随机初始密码登录，并成功修改 admin 密码
[ ] 另一台同局域网电脑能打开窗口显示的“同事访问”地址
[ ] 新建、冲突拦截、取消预约均正常
[ ] 用户和会议室的新增、编辑、停用/删除均正常
[ ] 双击“② 立即备份.bat”后只生成一个 .db 备份文件
[ ] “③ 设置开机自动启动.bat”通过 UAC，重启电脑后系统可访问
[ ] “④ 停止本次后台系统.bat”和“⑤ 取消开机自动启动.bat”符合提示
[ ] 单位防火墙/组策略拒绝时，已经由网管放行 TCP 8080（仅局域网）

本部署包在 macOS 环境完成了应用测试、浏览器测试和 Windows 文件静态审查；
Windows 的 UAC、防火墙、计划任务必须以本清单在单位实机确认一次。
