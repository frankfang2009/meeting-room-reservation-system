开发工作区说明
==============

源代码工作区
------------

用于后续修复和开发新版本。

注意：“源代码工作区\data”是 Mac 本机试玩产生的数据，包含本机管理员密码和会话密钥，禁止打包或发送给客户。


Windows部署目录-V1.0.0
----------------------

这是当前 Windows 交付包的解压参考目录，用于对照和制作后续升级包。
真正已经发给客户的原始 ZIP 保存在“01_版本归档”中。


Windows部署目录-V1.0.1-待实机验收
--------------------------------

这是已经组装好的 V1.0.1 完整部署候选目录。Mac 自动测试及 GitHub Windows PowerShell 5.1
的成功升级、重复运行和故障回滚均已通过；UAC、SmartScreen、计划任务和真实局域网访问
仍须在 Windows 10/11 实机人工验收。
验收前不要把它当成正式客户版本，也不要放入“01_版本归档”。


升级包工具
----------

这里包含单文件升级包生成器、PowerShell 事务逻辑、BAT 头部、完整累计负载和测试。
当前候选成品在“升级包工具\输出-待实机验收\升级到V1.0.1.bat”。
详细状态和校验值见“V1.0.1-候选版说明.txt”。


开发原则
--------

- V1.0.0 归档只读保存。
- 新修改只在本开发工作区进行。
- 发布新版本时重新生成干净 ZIP，不能包含 data、logs、backups、缓存或本机密码。
- V1.0.1 只有完成 Windows 10/11 实机 15 项人工验收后，才可建立正式归档和发送给客户。
