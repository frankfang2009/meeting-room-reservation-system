首次部署验收清单（给单位网管）
==============================

候选版本：V1.0.1（一键升级机制）

请在正式发给全员前，用单位的 Windows 电脑做一次：

[ ] 文件夹位于本地固定盘，路径不要太深，路径可包含中文和空格
[ ] 双击“① 启动系统.bat”能打开登录页
[ ] 重复双击“①”只会再次打开浏览器，不会启动第二套服务
[ ] 用随机初始密码登录，并成功修改 admin 密码
[ ] 另一台同局域网电脑能打开窗口显示的“同事访问”地址
[ ] 新建、冲突拦截、取消预约均正常
[ ] 用户和会议室的新增、编辑、停用/删除均正常
[ ] 双击“② 立即备份.bat”后只生成一个 .db 备份文件
[ ] “③ 设置开机自动启动.bat”通过 UAC，重启电脑后系统可访问
[ ] “④ 停止本次后台系统.bat”和“⑤ 取消开机自动启动.bat”符合提示
[ ] 单位防火墙/组策略拒绝时，已经由网管放行 TCP 8080（仅局域网）
[ ] 在一份 V1.0.0 测试副本上双击“升级到V1.0.1.bat”，旧用户、会议室和预约均保留
[ ] 再次双击同一升级文件时只提示“无需升级”
[ ] 用内部故障测试包验证失败后程序与数据库都会自动恢复
[ ] 连续双击两个升级窗口时，第二个窗口只提示“升级正在进行”
[ ] 设置开机自启和未设置开机自启两种状态下，升级后运行状态都与升级前一致

本部署包已通过 macOS 自动测试及 GitHub Windows PowerShell 5.1 的成功升级、重复运行和
故障回滚测试；Windows 的 UAC、SmartScreen、防火墙、计划任务和真实局域网访问仍必须
以本清单在单位实机确认一次。
