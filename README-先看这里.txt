会议室预约系统 V2.1.0 开发分支说明
===================================

一、当前方向
------------

本分支建立 V2.1.0 全新安装候选，不是 V1 累计升级。
V1 的账号、笔录室、预约、配置和数据库全部不导入；安装器也不会自动搜索、读取、
删除或覆盖旧系统目录。

正式实现位于：v2\
V1 历史证据位于：01_版本归档\、02_开发工作区\ 和旧 Git 提交


二、开发前先看
--------------

1. v2\docs\PRODUCT-CONTRACT.md
2. v2\docs\API-CONTRACT.md
3. v2\docs\ARCHITECTURE.md
4. v2\docs\RELEASE-CHECKLIST.md

角色只允许 admin 和 employee。登录后的预约日历对两者显示全单位完整详情，
employee 只能修改或取消本人预约；公开大屏只能使用服务端白名单脱敏响应。


三、给用户的最终安装方式
------------------------

用户收到完整“会议室预约系统-V2.1.0-安装包.zip”，完整解压后双击顶层
“安装V2.1.0.bat”。目标必须不存在或完全为空。若用户决定丢弃旧系统，需先自行
停止并删除旧内容；V2 安装器不代替用户删除旧系统。

首次设置完成前服务只监听 127.0.0.1:8080；创建管理员、至少一个笔录室和工作
时间后，服务重启并开放同一局域网访问。


四、发布状态
------------

普通用户 Windows 10/11 的 UAC、SmartScreen/EDR、计划任务重启、防火墙、第二台
局域网电脑和电视大屏验收全部通过前，任何 V2.1.0 ZIP 都只是候选版，不能写成
正式外发通过。
