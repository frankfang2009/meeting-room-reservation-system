会议室预约系统文件夹说明
========================

当前正式版本：V1.0.0 初始发布版


一、已经发给客户的版本在哪里
----------------------------

打开：
01_版本归档\V1.0.0_初始发布版\01_交付给客户

需要发给客户时，只发送这里面的两个文件：

1. 会议室预约系统-单位局域网版-最终.zip
2. 会议室预约系统-README用户指南.pdf

不要把“02_开发工作区”发给客户。


二、以后在哪里开发升级
----------------------

源代码位置：
02_开发工作区\源代码工作区

Windows 解压参考目录：
02_开发工作区\Windows部署目录-V1.0.0

后续版本应另建 V1.0.1、V1.1.0 等目录，不要直接修改 V1.0.0 归档。

当前 V1.0.1 升级机制候选版位于：
02_开发工作区\升级包工具\输出-待实机验收\升级到V1.0.1.bat

完整候选部署目录位于：
02_开发工作区\Windows部署目录-V1.0.1-待实机验收

R1 修复版已经通过 Mac 自动测试，尚待重新通过 GitHub Windows 自动化并完成 Windows 10/11
实机人工验收，因此当前正式版本仍是
V1.0.0，也不得把候选版放入“01_版本归档”或直接发给客户。详细校验值见：
02_开发工作区\V1.0.1-候选版说明.txt


三、重要提醒
------------

- “源代码工作区\data”是本机试玩产生的数据，里面包含本机密码和密钥，绝对不要外发。
- 客户的账号、密码、会议室和预约数据保存在客户电脑的“_程序文件\data”中。
- 后续升级必须保留客户的 data 文件夹，不能让客户重新安装或覆盖数据。
- 根目录的“.venv-local”是 Mac 本机试玩环境，属于隐藏开发文件。
