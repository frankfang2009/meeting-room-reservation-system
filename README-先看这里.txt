会议室预约系统文件夹说明
========================

当前正式版本：V1.0.2


一、给现有客户升级时发送什么
----------------------------

打开：
02_开发工作区\升级包工具\输出-待实机验收

只发送同一正式版本的这两个文件：

1. 升级到V1.0.2.bat
2. V1.0.2-发布清单.json

客户只需运行 BAT；发布清单用于核对文件是否损坏。不要把整个“02_开发工作区”、
发布暂存目录、源码、测试、data、logs、runtime 或首次登录账号密码发给客户。

新装机器仍以 V1.0.0 正式归档为安装基线，再立即运行 V1.0.2 累计升级包；在另行制作并
验证 V1.0.2 完整部署归档前，不要把“发布暂存”中的候选目录直接当作新装交付物。


二、以后在哪里开发升级
----------------------

源代码位置：
02_开发工作区\源代码工作区

Windows 解压参考目录：
02_开发工作区\Windows部署目录-V1.0.0

后续版本从唯一源码自动组装到“02_开发工作区\发布暂存”，不要直接修改 V1.0.0 归档。

当前 V1.0.2 正式升级包位于：
02_开发工作区\升级包工具\输出-待实机验收\升级到V1.0.2.bat

与正式 BAT 成对的发布清单位于：
02_开发工作区\升级包工具\输出-待实机验收\V1.0.2-发布清单.json

自动组装的完整候选部署目录仍保留为历史生成与验证证据：
02_开发工作区\发布暂存\V1.0.2\Windows部署目录-V1.0.2-待实机验收

V1.0.1 候选包和候选部署目录必须保持不变，作为 V1.0.2 跨版本升级与回滚基线。
V1.0.2 已通过自动化验证，并于 2026-07-26 由用户确认在现有客户环境升级成功。
不得重新生成或改写已经验收的正式 BAT、发布清单及其历史候选记录。


三、重要提醒
------------

- “源代码工作区\data”是本机试玩产生的数据，里面包含本机密码和密钥，绝对不要外发。
- 客户的账号、密码、会议室和预约数据保存在客户电脑的“_程序文件\data”中。
- 后续升级必须保留客户的 data 文件夹，不能让客户重新安装或覆盖数据。
- 根目录的“.venv-local”是 Mac 本机试玩环境，属于隐藏开发文件。
