# 会议室预约系统

单位局域网使用的轻量会议室预约系统，以及面向 Windows 10/11 的单文件累计升级机制。

当前开发目标：V1.0.2 候选版。V1.0.1 候选物保持冻结，作为升级与回滚基线。
V1.0.2 完成自动化验证后仍须通过真实 Windows 10/11 人工验收，才能视为正式发布。

## 目录

- `02_开发工作区/源代码工作区`：Flask 应用、数据库迁移框架和业务测试。
- `02_开发工作区/升级包工具`：发布骨架、一键发布组装器、BAT 生成器、PowerShell 5.1 升级事务和测试。
- `02_开发工作区/发布暂存`：从唯一源码自动生成的版本化候选物，不作为源码维护。
- `02_开发工作区/Windows部署目录-V1.0.0`：旧版测试基线；版本库不跟踪 runtime 和数据，本机可保留冻结 runtime 用于验证。
- `02_开发工作区/Windows部署目录-V1.0.1-待实机验收`：冻结候选基线；版本库不跟踪 runtime 和数据，本机完整候选使用同一冻结 runtime。
- `02_开发工作区/升级机制实施计划.md`：升级、回滚和验收规则。

## 测试

本地业务与迁移测试：

```bash
cd 02_开发工作区/源代码工作区
python -m unittest discover -s tests -v
```

升级包生成器测试：

```bash
cd 02_开发工作区/升级包工具
python -m unittest discover -s tests -v
```

GitHub Actions 的 Windows PowerShell 5.1 作业会从唯一源码重新组装发布负载，核对精确候选
BAT，并在临时安装目录验证：

- V1.0.0 直接升级到当前目标版本；
- V1.0.1 升级到当前目标版本；
- 用户、会议室、预约、会话密钥和数据库结构保留；
- 同一 BAT 重复运行安全退出；
- 两种旧版本起点的故障 Payload 都能恢复旧程序、旧版本文件和旧数据。

交互式 UAC、SmartScreen、真实开机计划任务和物理断电仍须在真实 Windows 10/11 电脑验收。

## 安全

仓库忽略所有 `data`、`logs`、`backups`、runtime、本机虚拟环境、数据库、首次登录凭据、
正式交付归档和发布暂存。只追踪明确用于实机验收的候选 BAT 与发布清单；不要把客户安装
目录直接复制到仓库。
